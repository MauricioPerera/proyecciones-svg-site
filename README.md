# Proyecciones SVG · sitio web

Landing en español con ejemplos vectoriales interactivos, instalación asistida y por terminal, peticiones para Codex, formatos de salida, límites y preguntas frecuentes.

**Sitio:** https://mauricioperera.github.io/proyecciones-svg-site/

Este repositorio contiene únicamente la página estática y ejemplos ilustrativos. La skill y su release 1.0.0 siguen en el repositorio privado `MauricioPerera/proyecciones-svg`; su descarga requiere acceso. Los ejemplos del sitio se pueden explorar y descargar públicamente.

## Vista previa local

```sh
python -m http.server 8770 --bind 127.0.0.1 --directory docs
```

Abre http://127.0.0.1:8770/. No se necesitan dependencias ni compilación. GitHub Pages publica desde `main`, carpeta `/docs`.

La fuente canónica de la landing y el programa de generación de sus ejemplos se mantienen junto a la skill en su repositorio privado. Esta copia pública no contiene el generador Python, claves ni credenciales.
